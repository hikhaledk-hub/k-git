02 ما هو Git؟ What is Git?

  • ✓نظام للتحكم في الإصدارات Version Control System يُسجّل كل تغيير يتم على ملفات المشروع.
  • ✓يساعد المبرمجين على تتبّع التغييرات في ملفات المشروع وتوثيقها.
  • ✓يسمح بالالرجوع إلى الإصدارات السابقة بضغطة واحدة History / Rollback.
  • ✓يساعد على تنظيم العمل البرمجي وتفادي الازدواج والتضارب.
💡

مثال توضيحي

الاحتفاظ بنسخ متعددة من المشروع دون الحاجة إلى إنشاء ملفات جديدة يدويًا — بدلًا من project-v1 و project-v2-final-new، يحتفظ Git بكامل التاريخ داخل مجلد واحد خفي .git.

04 ما هو GitHub؟ What is GitHub?

  • ✓منصة إلكترونية لاستضافة المشاريع البرمجية Hosting Platform.
  • ✓تعتمد على نظام Git كمحرّك أساسي لإدارة الإصدارات.
  • ✓تسمح بـحفظ المشاريع عبر الإنترنت والوصول إليها من أي جهاز.
  • ✓تساعد المبرمجين على مشاركة الأكواد والتعاون في مساحة واحدة.

github.com

أكثر من 420 مليون مستودع Repository — مجتمع عالمي للمطورين.

05 الفرق بين Git وGitHub

🔴 Git

  • نظام للتحكم في الإصدارات Version Control.
  • يعمل على جهاز الكمبيوتر محليًا Local.
  • يتتبّع التغييرات في الملفات داخليًا.
  • برنامج يحتاج تثبيتًا، ولا يحتاج اتصال إنترنت.
VS

🔵 GitHub

  • منصة لاستضافة المشاريع Hosting.
  • تعمل عبر الإنترنت Cloud.
  • تسهّل مشاركة المشاريع والتعاون الجماعي.
  • موقع ويب يحتاج اتصالًا، ويستضيف مستودعات Git.

06 أهم مصطلحات Git Key Terms

Repository
المستودع

مكان حفظ ملفات المشروع وسجل تغييراته كاملًا.

Commit
حفظ التغييرات

تسجيل نسخة من التعديلات في سجل المشروع.

Branch
الفرع

مسار مستقل للعمل على المشروع دون التأثير على الآخرين.

Merge
الدمج

دمج التعديلات من فرع إلى آخر.

Clone
الاستنساخ

نسخ مستودع كامل إلى جهازك.

Push
الرفع

إرسال التعديلات المحلية إلى GitHub.

Pull
السحب

جلب التحديثات من المستودع البعيد إلى جهازك.

Remote
النقطة البعيدة

نسخة المشروع المخزّنة على الخادم/الإنترنت.

08 أهم أوامر Git Basic Commands

bash
$ git init
تهيئة مستودع جديد في المجلد الحالي.
bash
$ git status
معرفة حالة الملفات (معدّل / مضاف / جديد).
bash
$ git add .
إضافة جميع الملفات إلى منطقة التجهيز.
bash
$ git commit -m "Initial commit"
تسجيل التغييرات برسالة وصفية.
bash
$ git push
رفع التغييرات المحلية إلى GitHub.
bash
$ git pull
جلب آخر التحديثات من المستودع البعيد.
bash
$ git clone <url>
نسخ مستودع موجود من الإنترنت إلى جهازك.
bash
$ git log --oneline
عرض سجل التعديلات بشكل مختصر.

09 فوائد GitHub والعمل الجماعي Collaboration

  • ✓التعاون بين المبرمجين على مستودع واحد من أي مكان في العالم.
  • ✓مشاركة المشاريع البرمجية علنًا أو ضمن فريق مغلق.
  • ✓متابعة التعديلات عبر سجل الإصدارات ونظام القضايا Issues.
  • ✓المساهمة في المشاريع مفتوحة المصدر Open Source.
  • ✓استخدام Pull Requests لمراجعة ودمج التعديلات بأمان.
  • ✓بناء ملف أعمال برمجي Portfolio يظهر مشاريعك لأصحاب العمل.
